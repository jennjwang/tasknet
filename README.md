# TaskNet

Interactive dashboard for *TaskNet: Building Occupational Task Inventories from Worker Interviews at Scale* (Wang, Haupt, Robinson, Lewis, Brynjolfsson, Yang).

- `index.html`: the dashboard
- `explorer.html`: the task Venn explorer, embedded in the dashboard
- `data.csv`: the 202 TaskNet statements and 118 O*NET 31.0 tasks with their ratings (O*NET tasks carry only the relevance, importance and frequency O*NET publishes)
- `relationships.csv`: links between TaskNet statements and O*NET tasks (overlaps / refines)
